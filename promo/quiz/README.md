# «Готов к ЕНТ? 5 вопросов» (Reels / TikTok)

Формат (по референсу quiz_storm1): титр «Ответишь на 5 вопросов, значит готов к ЕНТ», 5 вопросов из банка
приложения, уровни 1–5 (лёгкий → невозможно) с зачёркиванием, таймер 3 с, голос читает вопрос и ответ.
Ответ на 1-й вопрос только в самом конце (удержание), после 2-го «тапни 2 раза», в конце быстро:
«сколько из 5? пиши в комменты, дальше тренируйся в боте, платить ничего не надо». Слово «бесплатно» не используем.

## Как выпускать на Mac (без Claude и без лимитов)
1. Один раз: `./setup_mac.sh`
2. Голос:
   - ElevenLabs (живее всего, как в пилоте): `export ELEVENLABS_API_KEY=...` (ключ: elevenlabs.io → Profile → API keys).
     Голос Liam (`ELEVEN_VOICE`), русский на `eleven_multilingual_v2`, казахский на `eleven_v3`. Повторяющиеся фразы кэшируются.
   - без ключа автоматически берётся Microsoft Edge: ru-RU-DmitryNeural / kk-KZ-DauletNeural, без лимитов.
3. `./make.sh 5` → 5 новых выпусков × RU и KK в `out/` (+ подписи к постам `.txt`).

## Файлы
- `pick.py` дописывает выпуски в `episodes.json`: по вопросу из истории, математики, биологии, химии, физики;
  сначала лёгкие, потом короткие средние; без формул и без повторов (`used.json`). Хватит примерно на 75 выпусков.
- `say.json` как произносить вопросы с формулами/цифрами, если хочешь взять их руками
- `script.py` текст озвучки (12 фраз): интро, Q1, (Q, ответ)×4, ответ на Q1, призыв
- `quiz.html` шаблон кадра, `render_ep.js` рендер кадров (Playwright), `sfx.py` сухие звуки (тики, щелчки)
- `build.py N ru|kk --eleven | --edge VOICE | --voice file.mp3 --cuts ...` собирает один ролик

Поменять тексты интро/призыва: `script.py` (голос) и `quiz.html` (TXT, экран).
