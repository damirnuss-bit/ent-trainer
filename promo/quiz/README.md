# «Готов к ЕНТ? 5 вопросов» (Reels / TikTok)

Формат: 5 простых вопросов из банка приложения, уровни 1–5 (лёгкий → невозможно) с зачёркиванием,
таймер-полоса, голос читает вопрос и ответ, ответ на 1-й вопрос только в самом конце (удержание),
в середине «тапни 2 раза», в конце «сколько из 5? пиши в комменты» + @enttrainer_bot.

Файлы:
- `pick.py` собирает выпуски в `episodes.json` (6 отобранных руками + `--auto N` из простых вопросов, без повторов, учёт в `used.json`)
- `say.json` как произносить вопросы/ответы с цифрами и формулами
- `script.py` текст озвучки (11 фраз), `python3 build.py N ru --script` печатает его и предупреждает о формулах
- `quiz.html` шаблон кадра, `render_ep.js` рендер кадров (Playwright), `sfx.py` сухие звуки
- `build.py` всё вместе: озвучка → таймлайн → звук → кадры → `out/epNN_lang.mp4` + подпись `out/epNN_lang.txt`

Озвучка:
- одним файлом: `python3 build.py 0 ru --voice voice/ep.mp3 --cuts 11.3,16.2,...` (границы 10 пауз между фразами)
- по фразам через Edge TTS (бесплатно, ru-RU-DmitryNeural / kk-KZ-DauletNeural): `python3 build.py 0 kk --edge kk-KZ-DauletNeural`
