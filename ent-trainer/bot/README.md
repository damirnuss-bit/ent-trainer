# Бот @enttrainer_bot

Файл `worker.js` отвечает на /start приветствием и кнопкой «Открыть тренажёр».
Хостинг: Cloudflare Workers, бесплатно.

1. dash.cloudflare.com → зарегистрироваться.
2. Workers & Pages → Create → Start with Hello World → имя `ent-bot` → Deploy.
3. Edit code → удалить всё → вставить `worker.js` → Deploy.
4. Settings → Variables and Secrets → Add → тип Secret, имя `BOT_TOKEN`, значение = токен из BotFather → Deploy.
5. Открыть в браузере `https://ent-bot.<ваш-поддомен>.workers.dev/setup` → должно быть «Готово ✅».

Шаг 5 сам ставит вебхук, описание бота (видно до нажатия «Старт»), команды и кнопку меню «Тренажёр».
Если меняете адрес приложения, поправьте `APP_URL` в начале файла и повторите шаг 5.

## Статистика: команда /stats
Пишет в бот только владелец (`mariachiman88`, или Telegram ID в переменной `OWNER_ID`). Показывает всего пользователей, новых и активных за день/неделю/месяц.

Нужна база D1 (один раз):
1. Workers & Pages → D1 → Create database → имя `ent-bot-stats`.
2. Воркер `ent-bot` → Settings → Bindings → Add → D1 database → Variable name `DB`, база `ent-bot-stats` → Deploy.
3. Открыть `/setup` (создаст таблицу).

Учёт идёт с момента подключения базы: кто писал боту и кто открывал тренажёр (приложение шлёт подписанный initData на `/seen`, воркер проверяет подпись).

## Оплата, лига, пульт (v0.4)

- Полный доступ за Telegram Stars: цена `PREMIUM_STARS` в начале `worker.js` (по умолчанию 250 ⭐), можно поменять переменной окружения воркера `PREMIUM_STARS`. Доступ действует до 31.08.2027.
- Команды: `/premium` (счёт в чате), `/paysupport`, `/terms` (Telegram требует их для оплаты звёздами), для владельца `/stats`, `/admin` (кнопка пульта), `/refund <user_id> <charge_id>` (возврат звёзд).
- После каждого изменения адреса или первого деплоя этой версии откройте `https://ent-bot.<поддомен>.workers.dev/setup`: вебхук начнёт получать `pre_checkout_query`, без этого оплата не пройдёт.
- База D1 `ent-bot-stats`: таблицы `users`, `activity` (уникальные по дням), `premium`, `league` создаются сами.

## Расчёт нагрузки (200 одновременно)

| Звено | Бесплатный лимит | Нагрузка при ~2000 активных в день (≈200 одновременно в пик) |
|---|---|---|
| GitHub Pages (приложение и банки) | ~100 ГБ трафика в месяц, CDN | новый ученик качает ~1,2 МБ (оболочка + 5 своих предметов в сжатом виде), дальше из кеша. 1000 новых в день ≈ 36 ГБ/мес |
| Cloudflare Worker (бот, оплата, лига) | 100 000 запросов/сутки, 10 мс CPU на запрос | ~6 запросов на ученика в день ≈ 12 000/сутки, пик меньше 2 запросов/сек; проверка подписи ~1 мс |
| D1 (база) | 5 млн чтений и 100 000 записей в сутки | ~3 записи на ученика в день ≈ 6 000; чтения с индексами ≈ 100 000 |

Запас по всем звеньям в 5-10 раз. Первым упрётся трафик GitHub Pages при 3000+ новых учеников в день: тогда перенести папку на Cloudflare Pages (трафик без лимита, бесплатно). Воркер при росте выше 100 000 запросов в сутки: тариф Workers Paid, 5 $ в месяц.
