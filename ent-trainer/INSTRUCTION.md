# Как выложить тренажёр ЕНТ в Telegram

Это инструкция для человека, который не программист. Всё делается в браузере, без установки программ. Время: около 40 минут. Деньги не нужны, платить нигде не придётся.

**Важно:** токен бота (длинная строка, которую выдаёт @BotFather) в этом проекте НЕ нужен. Никому его не отправляй и никуда не вставляй. Приложение работает без сервера.

---

## Что понадобится

1. Аккаунт в Telegram (он у тебя есть).
2. Электронная почта для регистрации на GitHub.
3. Папка проекта `ent-trainer` (архив `ent-trainer-v5.zip`, который прислал Claude).

---

## Уже выкладывал раньше? Как обновить до этой версии (5 минут)

1. Распакуй архив `ent-trainer-v5.zip` (шаг 1 ниже).
2. Открой свой репозиторий `ent-trainer` на GitHub, нажми **Add file**, затем **Upload files**.
3. Выдели всё внутри распакованной папки `ent-trainer` и перетащи в окно. GitHub заменит файлы с такими же именами.
4. Нажми **Commit changes**. Через 1-2 минуты в боте будет новая версия.
5. Важно: открой `js/config.js` на GitHub и проверь, что `botUsername`, `ownerUsername` и `examDate` не вернулись к `YOUR_...` (загрузка перезаписывает этот файл). Если вернулись, впиши заново по шагу 8. То же для `data/ads.json`.

Если выкладываешь впервые, пропусти этот раздел и иди по шагам ниже.

## Что нового в этой версии

- **Новый дизайн.** Нижняя навигация (Главная, Практика, Прогресс, Профиль), на главной прогноз баллов, активность за неделю, карточка «Продолжить» и предметы с процентом. Цвета берутся из темы Telegram, поэтому светлая и тёмная тема работают сами.
- **До ближайшего ЕНТ.** На главной показывается, сколько дней осталось и какая дата. Если у ЕНТ несколько потоков, впиши их в `examDates` в `js/config.js`, покажется ближайший будущий.
- **Прогресс.** Точность по предметам, три слабые темы и кнопка «Тренировать слабые темы».
- **Поддержка проекта.** На главной и в профиле кнопка «Поддержать». Открывается окно с номером карты (`donateCard` в `js/config.js`) и кнопкой «Скопировать». Чтобы убрать кнопку, сотри номер между кавычками.
- **Реклама выключена.** В `data/ads.json` все места отключены (`active: false`), на главной написано, что проект некоммерческий. Рекламный слот не удалён, включить его можно позже.
- **Пробный ЕНТ в трёх вариантах.** Кнопка «Пробный ЕНТ» теперь открывает выбор: «Вариант 1», «Вариант 2», «Вариант 3» или «Случайный набор». В каждом варианте 120 заданий, а вопросы из банка в разных вариантах не повторяются. В задачах по математике, матграмотности, части физики и химии числа подставляются случайно, поэтому они одного типа, но с другими числами.
- **Математика:** 71 шаблон задач с случайными числами (на их основе получаются тысячи разных заданий) плюс 52 готовые задачи: 25 на несколько верных ответов и 27 на соответствие. Теперь в варианте по математике есть все три типа заданий.
- **Любой предмет отдельно.** В «Тест по предмету» и «По темам» видны все 7 предметов.
- **Больше вопросов:** всего 2004 в банке: физика 459, биология 352, математика 338, химия 326, математическая грамотность 266, история 233, чтение 30 (6 текстов). Все со статусом draft. Около 600 из них числовые задачи с разными числами (одинаковые типы условий), остальные написаны отдельно.
- **Тексты для чтения** (Чарынский каньон, Аральское море, государственные праздники, Казахское ханство) написаны по открытым данным Википедии (лицензия CC BY-SA 4.0) и перепроверены по казахским сайтам. Эта ссылка на источник нужна по лицензии, она есть в `README.md`.

## Шаг 1. Распакуй архив

1. Найди скачанный файл `ent-trainer-v5.zip`.
2. На компьютере: правая кнопка, «Извлечь всё» (Windows) или двойной клик (Mac).
3. Должна получиться папка `ent-trainer`, внутри файлы `index.html`, `sw.js` и папки `js`, `css`, `data` и другие.

Если делаешь с телефона, проще сделать шаги 1 и 2 на компьютере.

---

## Шаг 2. Создай аккаунт GitHub

GitHub это бесплатное место, где будут лежать файлы приложения и откуда они будут открываться в Telegram.

1. Открой https://github.com и нажми **Sign up**.
2. Введи почту, придумай пароль и имя пользователя (логин). Запомни логин, он понадобится в адресе. Лучше короткий и латиницей, например `damir-ent`.
3. Подтверди почту кодом из письма.

---

## Шаг 3. Создай репозиторий (хранилище файлов)

1. На GitHub нажми **+** в правом верхнем углу, затем **New repository**.
2. **Repository name**: `ent-trainer`
3. Выбери **Public** (публичный). Это обязательно для бесплатной выкладки.
4. Поставь галочку **Add a README file**.
5. Нажми **Create repository**.

---

## Шаг 4. Загрузи файлы

1. В созданном репозитории нажми **Add file**, затем **Upload files**.
2. Открой на компьютере папку `ent-trainer`, выдели **всё внутри неё** (Ctrl+A на Windows, Cmd+A на Mac) и перетащи в окно браузера. Папки `js`, `css`, `data`, `docs`, `tests` перетаскиваются вместе с файлами внутри.
3. Подожди, пока все файлы загрузятся (внизу появится список).
4. Прокрути вниз и нажми зелёную кнопку **Commit changes**.

Проверка: на главной странице репозитория должны быть видны `index.html`, `sw.js`, папки `js`, `css`, `data`.

Если GitHub пишет, что файлов слишком много: загрузи сначала файлы из корня, потом каждую папку отдельно.

---

## Шаг 5. Включи бесплатный хостинг (GitHub Pages)

1. В репозитории открой **Settings** (шестерёнка, вкладка справа вверху).
2. В левом меню выбери **Pages**.
3. В блоке **Build and deployment** в поле **Source** выбери **Deploy from a branch**.
4. Ниже в **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
5. Подожди 1-2 минуты и обнови страницу. Вверху появится адрес:

   `https://ТВОЙ_ЛОГИН.github.io/ent-trainer/`

6. Открой этот адрес в браузере. Должен появиться экран «Тіл / Язык» с двумя кнопками. Если открылся, значит хостинг работает.

Запиши этот адрес, он нужен дальше. Адрес должен быть именно с `https://`, с `/` на конце.

---

## Шаг 6. Создай бота в @BotFather

1. В Telegram найди **@BotFather** (с синей галочкой) и нажми **Start**.
2. Отправь команду `/newbot`.
3. Он спросит **название** бота (то, что видят люди). Например: `ЕНТ Тренажёр`.
4. Потом спросит **username**: латиницей, обязательно заканчивается на `bot`. Например: `ent_trainer_kz_bot`. Если занят, придумай другой.
5. BotFather пришлёт сообщение с ссылкой на бота и токеном. **Токен никому не показывай и никуда не вставляй.** Запомни только username бота.

---

## Шаг 7. Подключи приложение к боту

1. Напиши **@BotFather** команду `/mybots`.
2. Выбери своего бота.
3. Нажми **Bot Settings**.
4. Нажми **Configure Mini App** (в некоторых версиях называется **Main App** или **Menu Button**, ищи пункт про Mini App).
5. Выбери **Enable Mini App** (включить).
6. Когда BotFather попросит адрес (URL), отправь адрес из шага 5: `https://ТВОЙ_ЛОГИН.github.io/ent-trainer/`
7. Если спросит про название кнопки, напиши `Открыть тренажёр`.

После этого в профиле бота и в чате с ним появится кнопка, которая запускает приложение.

Названия пунктов в BotFather иногда меняются. Если не нашёл точно такой, ищи любой пункт про **Mini App** или **Menu Button** и пришли мне скриншот, я подскажу.

---

## Шаг 8. Впиши имена бота и своё в настройки

В файлах стоят заглушки. Их нужно заменить на твои данные.

**Файл `js/config.js`:**

1. В репозитории на GitHub открой папку `js`, затем файл `config.js`.
2. Нажми значок карандаша (**Edit this file**).
3. Найди строку `botUsername: 'YOUR_BOT_USERNAME'` и замени `YOUR_BOT_USERNAME` на username бота **без** @. Например: `botUsername: 'ent_trainer_kz_bot'`.
4. Найди строку `ownerUsername: 'YOUR_TELEGRAM_USERNAME'` и впиши свой Telegram username без @. Туда будут приходить отчёты «Нашёл ошибку» и заявки от рекламодателей.
5. Найди `examDate: '2027-06-01'` и поставь дату ближайшего ЕНТ (формат год-месяц-день). Если потоков несколько, остальные даты впиши в `examDates: ['2027-03-20', ...]`: на главной покажется ближайшая будущая. Актуальные даты бери на сайте НЦТ.
6. Найди `donateCard` и проверь номер карты для поддержки проекта. Если не хочешь показывать кнопку «Поддержать», оставь пустые кавычки.
7. Нажми **Commit changes**, затем снова **Commit changes**.

**Файл `data/ads.json`:** сейчас не нужен, реклама выключена. Он понадобится, только когда захочешь продавать рекламное место: тогда замени `YOUR_TELEGRAM_USERNAME` на свой username и поставь `"active": true`.

---

## Шаг 9. Проверь на телефоне

1. Открой своего бота в Telegram и нажми кнопку запуска приложения.
2. Выбери язык и связку. Должен сразу появиться первый вопрос.
3. Ответь на вопрос. Телефон должен слегка завибрировать, а внизу появиться кнопка «Далее».
4. Пройди тренировку до конца и посмотри результат.
5. Закрой приложение посередине теста и открой снова. На главной должна быть кнопка «Продолжить».
6. На главной должна быть строка «До ближайшего ЕНТ» с числом дней, а внизу кнопка «Поддержать». Нажми её: откроется окно с номером карты, кнопка «Скопировать номер» должна показать «Номер скопирован».
7. Проверь тёмную тему: включи тёмную тему в Telegram и открой приложение. Цвета должны смениться сами.

Если что-то не так, посмотри раздел «Если не работает» внизу.

## Шаг 10. Описание бота (по желанию)

В @BotFather: `/mybots`, твой бот, **Edit Bot**:

- **Edit Description** (что видят до нажатия Start). Пример: «Бесплатная подготовка к ЕНТ: тесты по истории, математике, физике, химии, биологии, грамотности чтения. На казахском и русском. Разбор ошибок и прогноз баллов.»
- **Edit About** (короткая строка в профиле): «Бесплатный тренажёр ЕНТ на қазақша и по-русски».
- **Edit Botpic**: картинка бота.

Бета пока без проверки учителями, поэтому в описании можно добавить слово «бета».

## Как обновлять приложение потом

Всё делается на GitHub: открываешь файл, жмёшь карандаш, меняешь, **Commit changes**. Через 1-2 минуты изменения в Telegram. Закрывать и открывать приложение заново не нужно, оно подтягивает новое при следующем запуске.

Чтобы добавить новые вопросы, Claude в следующих чатах даст готовые файлы банка. Ты заменишь файл в папке `data/bank` (кнопка **Add file**, **Upload files**, перетащить файл с тем же именем, **Commit changes**).

## Статистика для продажи рекламы (по желанию, 10 минут)

Без сервера приложение само не знает, сколько у него пользователей. Есть два бесплатных способа.

**Способ 1. Простой: Cloudflare Web Analytics.** Показывает посетителей по дням. Регистрация на https://dash.cloudflare.com, раздел **Web Analytics**, добавить сайт `ТВОЙ_ЛОГИН.github.io`. Cloudflare даст кусочек кода с токеном. Его нужно вставить в `index.html` вместо закомментированной строки (там есть подсказка). Если запутаешься, попроси Claude помочь в отдельном чате.

**Способ 2. Подробный: Google Таблица.** Записывает каждого пользователя (Telegram ID), язык, связку, предметы, число запусков. Именно эти цифры нужны в медиакит. Скрипт лежит в файле `docs/apps-script.gs`, там же инструкция в первых строках. После настройки адрес скрипта вставляется в `js/config.js` в строку `trackUrl: ''`.

Собираются только Telegram ID, язык, связка и результаты. Телефоны и ИИН не собираются.

## Если не работает

| Что видишь | Что делать |
|---|---|
| Адрес `github.io` показывает ошибку 404 | Подожди 3-5 минут после включения Pages. Проверь, что репозиторий Public и что `index.html` лежит в корне, а не внутри вложенной папки. |
| Адрес открывается, но в боте белый экран | Проверь, что в @BotFather адрес именно с `https://` и `/` на конце и что страница открывается в обычном браузере. |
| Формулы показываются обычным текстом (x2 вместо красивого) | Не загрузилась библиотека формул (нужен интернет при первом запуске). После подключения к сети формулы станут красивыми. Не критично. |
| Нет вибрации | Включи вибрацию в настройках телефона. На некоторых Android вибрация в Telegram работает не всегда. |
| Не обновляется после правки | Подожди 2 минуты, полностью закрой приложение (смахни) и открой снова. |
| Кнопка «Нашёл ошибку» открывает чужой чат | Проверь `ownerUsername` в `js/config.js`. |
| В карточке результата написано `@YOUR_BOT_USERNAME` | Не заполнен `botUsername` в `js/config.js` (шаг 8). |
