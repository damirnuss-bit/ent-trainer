# ЕНТ Тренажёр (Telegram Mini App)

Статическое приложение: HTML + CSS + JavaScript, без сервера и без сборки. Хостинг GitHub Pages. Запуск для не программиста: см. `INSTRUCTION.md`.

## Структура

```
index.html            входная страница
sw.js                 офлайн-кеш (сначала сеть, потом кеш)
css/style.css         оформление, цвета из темы Telegram
js/config.js          все настройки (бот, дата ЕНТ, цель дня, trackUrl, KaTeX)
js/subjects.js        предметы, связки, темы, структура ЕНТ, баллы за типы заданий
js/i18n.js            тексты интерфейса ru и kk
js/app.js             экраны и ход теста
js/pool.js            сборка наборов вопросов, оценка, баллы ЕНТ
js/store.js           прогресс: localStorage + CloudStorage Telegram
js/tg.js              обёртка Telegram WebApp SDK (с запасным вариантом для браузера)
js/render.js          вывод текста и формул (KaTeX с CDN, запасной текстовый вариант)
js/track.js           статистика для рекламодателей (выключена, пока trackUrl пустой)
js/gen/*.js           генераторы задач по предметам
data/bank/*.json      банки вопросов по предметам
data/ads.json         реклама (баннер и партнёрская карточка)
docs/apps-script.gs   скрипт Google Таблицы для статистики
tests/                автотесты
```

## Тесты

```
node tests/gen-test.mjs        # 1000 прогонов каждого шаблона генератора
node tests/bank-test.mjs       # банки вопросов, сборка сессий, подсчёт баллов
node tests/variants-test.mjs   # 3 варианта пробного ЕНТ: 120 заданий, без общих вопросов, 5+5 заданий на несколько ответов и соответствие
node tests/text-test.mjs       # тексты ru/kk, смесь алфавитов, длинные тире
python3 tests/ui-smoke.py              # интерфейс в headless Chromium (нужен playwright)
python3 tests/ui-telegram-mock.py      # интерфейс на имитации Telegram WebApp
```

## Формат вопроса в банке

Файл `data/bank/<предмет>.json` это массив вопросов. Файлы: `history`, `reading`, `physics`, `chemistry`, `biology` (для математики и матграмотности банка нет, там генераторы).

```json
{
  "id": "bio-cell-0012",
  "subject": "biology",
  "topic": "cell",
  "type": "single",
  "difficulty": 2,
  "ru": {"text": "...", "options": ["...", "...", "...", "..."], "explanation": "..."},
  "kk": {"text": "...", "options": ["...", "...", "...", "..."], "explanation": "..."},
  "answer": [0],
  "status": "draft"
}
```

- `topic` это ключ темы из `js/subjects.js` (например `cell`, `gen`, `human`, `ecology`), а не русское название. Названия на двух языках лежат в `TOPICS`.
- `type`: `single` (один ответ), `multiple` (два и больше ответов, `answer` это список индексов), `match` (соответствие).
- `match`: в `ru` и `kk` добавляется `left` (левая колонка), `options` это правая колонка, `answer[i]` это индекс правого пункта для `left[i]`.
- `reading`: добавляются `set` (идентификатор текста, общий для его вопросов) и `passage` внутри `ru` и `kk`.
- `status`: `draft` (написан), `checked` (проверен учителем), `live`. На бете показываются все статусы (`allowedStatus` в `js/config.js`).
- Варианты ответов приложение перемешивает при каждом показе, порядок в файле значения не имеет.
- Id уникальный, число в конце растёт.

## Как добавить генератор

В файле нужного предмета в `js/gen/` добавить объект в массив `templates`:

```js
{ id: 'p-example', subject: 'physics', topic: 'mech', difficulty: 1,
  build(r) {
    // r.int(a, b), r.pick(массив), need(условие) для отбраковки некрасивых чисел
    return {
      ru: { t: 'Условие', e: 'Разбор' },
      kk: { t: 'Шарт', e: 'Талдау' },
      c: 'верный ответ',
      w: ['типичная ошибка 1', 'типичная ошибка 2', 'типичная ошибка 3', 'запасная']
    };
  } }
```

Формулы в тексте оборачиваются в `$...$` (KaTeX). Затем `node tests/gen-test.mjs`. Тест проверяет: нет ошибок за 1000 прогонов, 4 разных варианта, верный ответ присутствует в разборе, есть оба языка, нет длинных тире, не меньше 15 разных условий.

Одна и та же задача не показывается в одном тесте больше 5 раз (`MAX_PER_TEMPLATE` в `js/pool.js`), поэтому в блоке бывает меньше заданий, пока шаблонов мало. Повторов одного и того же вопроса из банка в тесте нет: если банк маленький, тест получается короче.

## Известные ограничения текущей версии

- Формулы KaTeX подгружаются с CDN (jsDelivr). Без сети показывается упрощённая текстовая запись. Отрисовка настоящим KaTeX не проверялась, проверялась только запасная.
- Структура профильного теста (30 заданий с одним ответом, 5 с несколькими, 5 на соответствие, 1 или 2 балла) принята по умолчанию в `js/subjects.js` и ждёт сверки со спецификацией НЦТ (этап 4). Правило «1 балл при одной ошибке» в заданиях с несколькими ответами тоже допущение.
- Дата основного ЕНТ в `js/config.js` ориентировочная.
- Статистика для рекламодателей включается отдельно (см. `docs/apps-script.gs`).
- Карточка результата это картинка в окне плюс ссылка на бота. Публикации прямо в сторис нет (для неё нужен публичный адрес картинки).
- Напоминания, рейтинг и реферальная ссылка требуют сервера и вынесены на этап 8.


## Варианты пробного ЕНТ

`js/pool.js`: `VARIANTS = 3`. Банк каждого предмета делится на варианты один раз и всегда одинаково (фиксированное зерно, сортировка по id), поэтому «Вариант 2» это один и тот же набор. Типы заданий и тексты для чтения делятся поровну. Чтобы получить больше вариантов, добавь вопросы в банки (на каждый вариант нужно: история 20, чтение 2 текста, физика 16, химия 20, биология 34 вопроса банка, из них 5 на несколько ответов и 5 на соответствие в профильных предметах), поставь нужное число в `VARIANTS` и запусти `node tests/variants-test.mjs`.

Ограничение: в математике (только генераторы) пока нет заданий на несколько ответов и на соответствие.

- Исторические даты сверены по ru.wikipedia.org («История Казахстана», «Казахское ханство») и учебным материалам: Касым-хан 1511 по 1521, Тауке-хан 1680 по 1718.
- Статус всех вопросов `draft`. Перед запуском для широкой аудитории казахский текст и даты должен проверить учитель.

## Источники вопросов (v5)

Новые вопросы по истории Казахстана написаны по учебнику для 10 класса (Мектеп, 2019, экземпляр с okulyk.kz). Факты взяты из учебника, формулировки собственные. Все вопросы в статусе draft, казахский нужно показать учителю.

## Объём банка (v5)

Всего 2004 вопроса: физика 459, биология 352, математика 338, химия 326, математическая грамотность 266 (раньше банка не было, только генераторы), история 233, чтение 30. Все со статусом draft, казахский текст нужно показать учителю.
Около 600 заданий (математика, физика, химия, математическая грамотность) это числовые задачи одного типа с разными числами. Они проверены кодом, но по содержанию повторяются, поэтому для разнообразия работают и генераторы.
Исправлено в движке: генераторы `ml-mean2` и `m-mid` иногда не собирали вопрос, а при нехватке заданий в блоке пробный ЕНТ мог получиться на одно задание короче (теперь добираем из банка).

## Интерфейс (v5)

Дизайн «Ночь»: нижняя навигация из четырёх вкладок (`js/app.js`: `TABS`, `renderTabs`), главная с прогнозом и активностью за неделю, экран прогресса со слабыми темами, окно «Поддержать» (`supportSheet`). Цвета берутся из темы Telegram, запасные заданы в `css/style.css`. Число ответов по дням хранится в `store.hist` (последние 14 дней). Дата ЕНТ: `examDate` и `examDates` в `js/config.js`. Реклама отключена в `data/ads.json`, код слотов оставлен.
